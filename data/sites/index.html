💡 How to Deploy Your Projects to ChimpSites

You can host Vite, React, Vue, MkDocs, Astro, or plain HTML/CSS static builds:

1. React / Vite / Vue (SPA)
# Build production files npm run build # Copy build folder to server scp -r dist/* u0_a223@<IP>:~/server/data/sites/my-app/
2. In-Browser / Drag & Drop
1. Open Chimp File Manager 2. Navigate to data/sites/ 3. Create folder: "portfolio" 4. Drag & drop index.html & assets
3. Instant URL Route
Any folder "my-app" is served at: http://<IP>:8080/sites/my-app/ Index file served automatically.
